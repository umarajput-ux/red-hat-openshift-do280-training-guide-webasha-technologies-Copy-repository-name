# Red Hat OpenShift DO280 Training and Administration Guide

This repository provides learning resources for understanding Red Hat OpenShift administration and Kubernetes-based application platforms.

## Topics Covered

- OpenShift architecture and cluster fundamentals
- Kubernetes pods, deployments, and workloads
- Application deployment and rollout management
- Services, routes, and networking
- Persistent storage fundamentals
- Role-based access control (RBAC) and security
- Troubleshooting pods and application deployments
- Practical administration exercises in a lab environment

## Getting Started

1. Learn the fundamentals of Linux and containers.
2. Explore Kubernetes workloads and resource management.
3. Practice using the OpenShift command-line interface (`oc`).
4. Deploy a sample application in an authorized lab.
5. Inspect resource status, events, and application logs.
